# Project Rules & Guidelines

These rules are loaded automatically and must be strictly followed for any development task in this codebase.

## Codebase Integrity & Reuse Guidelines

- **Scan Before Action**: Before making any changes, scan the entire codebase to understand the existing structure, utilities, CSS rules, and component styles.
- **Reuse Existing Code & Assets**: Reuse existing folders, files, components, utilities, stylesheets (CSS), and assets as much as possible.
- **No Duplication**: Never create duplicate folders, files, or functions if equivalent versions already exist.
- **Update, Don't Replace**: Update existing files with targeted modifications instead of replacing or overwriting them completely.
- **Strict Folder/File Creation**: Only create a new folder or file if absolutely no equivalent exists anywhere in the project.
- **Style and Structure Consistency**: Always follow the existing project structure, naming conventions, and coding styles.
